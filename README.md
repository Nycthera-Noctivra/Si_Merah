# Apasih Si Merah itu?
Nah _Si Merah_ adalah aplikasi yang dirancang khusus untuk membantu petani dan pelaku agrikultur dalam mendeteksi penyakit tanaman cabai secara cepat dan akurat. Menggunakan teknologi object detection YOLOv8, aplikasi ini mampu mengenali berbagai jenis hama dan penyakit pada daun maupun buah cabai hanya melalui foto smartphone.
